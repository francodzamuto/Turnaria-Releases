# Turnaria — versiones oficiales

Canal público de instalación y actualización de Turnaria.

Este repositorio contiene únicamente instaladores, archivos de verificación y metadatos de actualización. El código fuente de Turnaria permanece en un repositorio privado.

Creada y desarrollada por Franco Zamuto.

## Seguridad

Las guardias, usuarios, adjuntos, claves y configuraciones de cada organización no se almacenan en este repositorio.
